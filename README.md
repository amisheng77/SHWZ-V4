# SHWZ — 《山河无主》

**现行基线：Canon V4.34（D1—D121）｜逻辑89章（正文86＋后记3），章节骨架V5.7；前五章已确认，CH06—15仍待作者裁决。**

> **山河可以无主，英雄不可无光；历史可以冷酷，传奇必须炽烈。**

这是一部春秋战国架空背景的历史奇幻传奇。**D111 已正式废止旧副标题，现行书名仅《山河无主》；第一部暂无正式副标题，《乌金战争》只是未定候选。故事核心：英雄们利用乌金改变了天下。 **D112 新增三位子爵封君各异的权力与识才体系，以及骥同龄将领重伤幸存线；详见人物档案03。**

**D102／D103 创作宪法重构（2026-10-19）**：`docs/00_创作宪法.md` 以**历史奇幻传奇类型承诺＋三条最高创作纪律**起篇：**人物必须鲜明；主要矛盾必须明确；巫术与神异受限但必须具象、震撼、惊诧乃至惊恐**。不强加灰度、反向例外或“画蛇添足”的中立解释。**萨巫＝西海古部族遗脉现忠草原的实际帮凶（不仇恨中原）；宿巫＝约 Y-50 青吞并的前朝后裔宿公国遗巫，一心复国或乱天下**。详 [创作宪法](docs/00_创作宪法.md)。

**D99—D101 第一性原理、三公子与国战审计**：抓核心矛盾／人物雄心／决定性行动／实际胜负，不让制衡风险削弱传奇。**老雍王为亲自变法强国、拍板攻梁与择贤立骥的雄主**；公子斯仁厚而优柔寡断、守成而非争霸；**公子铎豪爽、有志振兴梁国，但治国才略不足、战略不决、驭臣失败，卫离擅刺骥与献都最终酿成亡国悲剧**；公子骥奉父王命立功择储。**朔派数千援军入梁东战而受挫，青陈兵国境不入梁作战；梁亡后雍得大部、部分东／东北郡县实归青朔**。详 [D99—D101 逆向审计报告](docs/reports/2026-10-18_第一性原理_人物与战争逆向审计_D99-D101.md)。

**D98 仲符新结局**：梁亡后公子骥军功过盛，公子斯／毕原君保守派以仲符真实政务失误反攻；在位国君也权衡朝堂失衡。仲符**主动辞去上卿，非放逐**；骥真诚挽留、师徒长谈，并请国君为老师保留小食邑。骥继位后礼请老师复出未果，改资助乡学，仲符晚年著书育人。**开战批准来自雍君和朝廷，未即位的骥只能奉命领军、争功争储。**污点细案尚属〔P〕。

**D97 并国旧土份额**：三分当时𬩽＋梁合计 50%，河35%，雍朔青趁乱合计取得15%，非 Y4／Y17 实控国境或国力比；梁弱而居要地不能单独解释雍 Y14 何以起兵。

**D96 战争分期再修正**：雍 Y14 只求部分边地或梁臣服等**有限目标**；天下御兽联盟已成，列国战争须有名分与抗兽军粮成本；**Y15 刺骥后至 Y17 才升级为解除梁国独立国格的灭国战**。**D101 已确认故梁东／东北部分郡县实际归青朔、雍得大部**，具体界线仍待 Y17 地图核验。专项分析 V1.1 见下文链接。

**D95 历史—战争前史（按 D101 新战况理解）**：并国旧强、三分后雍朔反压；Y14 雍主动东出战争、Y15 卫离刺骥、Y17 梁亡。**朔有限援梁与青朔战后实际受梁东郡县，以 D101 和本次报告为准**。

**D94 最新史因裁决**：雍朔旧人战 **𬩽助雍、梁助朔**；后来朔报复进攻𬩽中东部，**𬩽西三郡归附雍并得雍军保护**。雍非与朔共同灭𬩽，煤亦非战因。正式名仍为「𬩽」。深山有巨蟒、瘴气与山崩；列国虽彼此竞争，仍能凭工艺、知识、军队和信义跨越艰险，完成可靠乌金终杀（D93）。现行审美全面依 D92：不以历史解释削弱英雄功业，不以神异退潮压低巨兽奇观与战场惊怖。
