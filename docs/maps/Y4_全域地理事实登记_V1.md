## 2. Y4 国别及历史地理（作者终裁）

- **北𬩽／中梁／南河**：北方旧𬩽国已在 Y4 以前被雍、朔瓜分，是旧国故地而非现存独立诸侯；中部梁国继续独立，南部河国继续独立。这是把旧北河国和旧南𬩽国的名称与相关历史指称对调，不改变梁国位置。
- **河水主干流向不变**：西部高原 → 雍国 → **河国**（旧文档误写𬩽国）→ 王庭 → 青国 → **青国北部单一河口入北海**。北部历史支流应按现行地名理解为北部高地 → 𬩽故地 → 梁国 → 河国 → 河水。河流走向不因国名互换而改。
- **王庭与文国**：边界按手绘图不变，双方均处于同一河水支流的东岸；**天邑在偏西河滨位置**（此处“偏西”指地图所示城址位置，不擅自断言位于支流西岸）。
- **湄国沿海、峤国内陆**：作者纠正旧文档“湄偏内陆、峤偏沿海”“湄掌上游、峤掌河口”之说。青沧之间仍为湄、峤两国，湄国沿海的**竹山岛**为青沧海战争议岛屿与事件地理中心；既定 Y5—7 假旗/邝/蛟窗战争因果不变。
- **海洋贸易**：青有海北贸易、沧有海东贸易、荆有海南贸易；三者都有独立航海网络，沧国不垄断所有外海商路。

## 4. 主要水系与湖泽

- **朔**：霁垣与沽阳沿同一河流相连，可经河道运输，沽阳对应旧称“朔东港”的既定海上窗口；朔国其他海岸可多陡崖、礁滩，良港稀少。
- **荆中部水系**：皋阳、顺州都位于其中；这是荆王可直接控制的核心流域；顺州为王室控制的重要出海港。
- **荆东部水系**：云州位于此流域，属云阳君封地；宜州不按东部河港处理，而是靠芮国的东北陆路重镇。
- **荆西部水系**：上游东、西两条主要支流汇合，在**中游形成云梦泽式湖泽**；下游继续南流。西、中、东三套水系各自独立，不合并。
- **沧北大湖**：以太湖为原型，图中黑色空心圆表示。
- **西海**：西北荒原与西部高寒地区交界区域，类似青海湖的大型内陆咸水湖；原始手绘图**尚未画出**。不与外海相通。
- **山濮**：红点表示北区森林部落、中南部河谷部落、下游滨海部落的重要聚落，不代表统一国家的都城或城制；已知乌金矿脉使用南部五角星。

## 5. 海岛与特殊地点

- **竹山岛**：湄国沿海，青沧海战争议岛、东海红色五角星；不将其误放峤国。具体海战锚地、岛上政务、航道与泊税细节仍待情节层落实。
- **岱山岛**：青国东北部海岛，青鸾栖息地、红色五角星；与竹山岛不是同一海岛，青鸾仍自择合作、不受人为驯养。
- 其他大小岛屿暂不命名。岛屿未命名不等于没有居民、航道或锚地。
- **雍国煤铁矿脉**：其五角星可指向矿业区域，不推出煤与铁必须同矿区；河西煤战后逐渐开发、不是 Y-7—Y-5 战争动机。

2. **作者人物归属终裁（选 A）**：原南𬩽国青年辩士**子献**随地理命名更正为**河国青年辩士**，Y4 以河国随员身份赴天邑，非王族，学宫与缓冲国生存主义及邝旧怨不变；**子献不是北𬩽亡国遗民**。另有一位不具名的北𬩽亡国旧族青年，随他国代表团出现，属于不同人物。不能把已灭北国写成仍能派遣正式使节。
