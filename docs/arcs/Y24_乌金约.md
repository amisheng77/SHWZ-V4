# 0. 乌金约的真正定位

乌金约不是"现代多边条约"。

它是：

> **丛林法则的收据：盟书极短、诅咒担保；实质内容是一份质剂总账——封几矿、开几山、纳几赋。**

战后秩序不是谈出来的，是打出来的：

> **会盟是打仗的收据**——席位与份额在终战最后一周的实际控制线上换算（U44 尾拍）。

签得成的原因不是天下道德高尚，是：

> **已勘优质矿脉本代趋枯**（至少已知者）——各国算过账，没得挖了，才肯封账封产。

但——

> **地质没签字。** 条约把"资源已尽"写成制度；封得最死的山，恰是最可能出新矿的地方。

后世可能把这一年压缩成：

> "诸侯盟于天邑，约以封矿。"

但正文必须让读者知道：

> **台面上的每一笔，台面下都有过假数、谍报、递证与讨价还价。**

# 1. 四层空间（镜像 Y4，色调反转）

1. **王庭**（图章化）：天子主歃血、加冕居上——仪式最高位给虚君；议程与他无关；
2. **质剂房（新设，Y4 没有的"账房"层）**：总账陈列、合券为信、核验造册——本场景真正的权力中心；
3. **馆舍与宴席**：讨价还价暗场；**衷甲一笔**（某使团袍下暗甲，看破不说破）；
4. **天邑市井**：候人细作互数粮车——间谍层唯一登台窗的面目在此给足。

---

# 2. 出场人物层级（谁在桌、谁在桌边、谁不在桌）

**在桌**：骥（雍）／新荆王／岱（青）——三雄主定事；老天子＝图章。
**桌边**：女史（记录者）／子易（受证核账人，非全知）／舟月（交权换监矿）。
**暗场**：青锋行动网（匿名递证，不露面）／杜若（商网在场，非使团）。
**不在桌**：萨巫——**本季定位＝漠北帮凶（作者终裁）：预警只给草原各部，不预警列国；列国不会给漠北一侧的人席位，题中应有之义**；不进条约，萨线留在朔/终楠线上走；临风（已辞兵符南去）。
**全程缺席而全场在场**：渤——无主功劳记「联盟」，无人提他一个字，读者自会算。

# 3. 丛林法则的台面（讨价还价 beats，暂列主干）

1. **抢席位**（U44 尾拍）：实际控制线换算份额——会盟是打仗的收据；
2. **争左券/先歃**：骥 vs 新青王，由「天子先歃」第三案解开——**共主虚化不是宣言，是谈判解的副产品**；
3. **衷甲一笔**：看破不说破，信息差归读者；
4. **交质名单**：质子条款——第二部人物钩（具体人名 §9 暂不设计）。

# 4. 存量暗战＝间谍层唯一登台窗

**四器官（全部复用现有资产，不造机构）**：
- 雍：反间机器转向外——审计式谍报（数渣堆、量车辙、核盐引，从物流残余倒推存量）；
- 沧/杜若：商网即谍网，价格信号即情报；
- 山盟：山地哨线——读兽迹的人读人更容易；
- **青国瞎**：耳目即渤网，已被它自己烧毁——这是雷的一半。

**递证链**：各国申报假数 → 子易只核可核之账 → 核不到处由青锋行动网匿名递证补上（行动网战后又一役——首役即除奸秉逐 CH75）→ 青国假账当众揭破。

**铁律**：情报＝拼图，不是全知——没有任何一方掌握全部真实数字。

# 5. 青国雷（读者的情感补偿机关）

- **镜像闭环**：CH15 礼单薄一档 → Y24 账本核减一档；
- **无主功劳**：最大一笔（南方枢纽＋海路＋粮运信用）记「联盟」——岱想争份额就必须援引那个人的功劳，**他杀了他，开不了口**；
- **三句对白封顶**：岱一句（"青国之输，天下共见"）、核账回一个数、完——最狠的羞辱是审计没错；
- **章尾小动作**：岱带恨离邑，不回头（小动作清单已收）——第二部修正主义强权坯子；
- **反高潮不破**：台面上只有数字；历史不主持公道，但账目从不撒谎。

# 6. 文书三件套的质感（去条约感）

| 件 | 内容 | 质感 |
|---|---|---|
| 盟书 | 天子主歃血、诅咒担保，极短 | 侯马盟书式——违约的代价是存量与下次开战，不是国际法庭 |
| 质剂总账 | 左右券、合券为信；封几矿、开几山、纳几赋 | 全是数——谁操左券＝新的座次战；政治层无「永存」字样 |
| 交质名单 | 质子 | 第二部人物钩 |

**沧监矿**：沧以航路公共化换矿区监察权——验封/造册/年报于约制（巡查核验权，非驻军非主权）；**动机＝自保：沧离荆最近、复采首当其冲，监察权即预警权——不是高风亮节，是防火墙**；荆不反对＝信矿脉见底、视监察为闲职；核证"矿脉见底"的正是沧国核验官——最近的邻居攥着全天下最烫的预警权。

# 7. 雷区（第二部引信）

1. **封账封产＋矿脉见底**——地质没签字；封得最死的山最可能出新矿；新勘法现成（阿瑶读山术）；**第一个知道的是沧国核验官——签约时的"闲职"变头号资产，荆被自己签下的监察条款锁着**；
2. **埋书异文**——宣读版与坎埋版有差，女史独见（第四处版本裂缝，第二部考古钩）；
3. **岱带恨离邑**——青国＝富、空心、被一份准确的审计羞辱——修正主义强权坯子；
4. **无主功劳入账**——渤的方法被制度化为永久机器：每次合券，都是他叔父的鬼在验货（岱的长期渗毒）。
