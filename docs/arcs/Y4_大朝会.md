# 0. Y4的真正定位

Y4不是"天下为了狍鸮专门开的御兽会议"。

它是：

> **数年一次的天邑大朝会：列国朝觐天子（有时带封爵）＋学宫祭酒大会。**

北境御兽只是临时议题之一。

朝会进行期间，朔国为了让列国正视惨烈而真实的北境食人灾祸，运入**已经死亡的北兽尸骸**及战地技术证人，以实证求援，才迫使全场重新认识这个问题。

后世可能把这一年压缩成：

> "诸侯朝于天邑，因及北兽。"

但正文必须让读者知道：

> **当时绝大多数人来天邑，并不是为了狍鸮。**

# 8. 沧国女商人

建议将她与后来的：

> **杜若——公子渤的恋人 / 合作者 / 独立网络拥有者**

设为同一人物，避免重复功能角色。

Y4时她已经可以在天邑出现，但不是王庭正式宾客，也**不意味着她已经在天邑拥有成熟商铺、货栈或客栈网络**。

她此时真正的主营仍然是：

> **以沧国为根基、连接青国及沿海港口的高端丝绸与海上贸易。**

她本人来天邑的合理动机是：
- 天下大会使大量王族、使节、贵族与大商人短期集中；
- 观察内陆高端丝绸与外交礼物市场是否值得进一步进入；
- 见原本分散在不同国家、平时很难一次见齐的旧客与潜在客户；
- 判断各国信用、婚姻、礼物流向与政治风向；
- 借商旅身份收集情报、建立下一阶段联系人。

她在天邑可以：
- 借住/借用已有沧商、合作商人或客户的院落；
- 使用本地牙人、车行、客舍和中间人；
- 带少量样货、账目或礼物，但不亲自经营天邑日常仓储业务。

硬规则：

> **她来天邑是“看机会、看人、看风向”，不是突然把自己的商业中心搬到天邑。**

她的信息优势来自：

> **正式政治人物看不到的流动。**

她可能注意到：
- 哪个使团突然追加马匹；
- 哪个公子私下打听什么礼物；
- 谁的账期忽然改变；
- 谁在打听天邑宗室婚约；
- 谁突然购买北境地图；
- 谁的随从偷偷更换馆舍。

这些信息可来自她自己的观察、旧客闲谈、合作商人、本地牙人和海商网络，不要求她控制天邑的货栈。

Y4时她与渤的关系阶段正式锁定为：

> **已经认识，并有过数次真实商业/信息合作；彼此欣赏且已经存在私人吸引，但尚未成为稳定恋人。**

此时硬规则：
- 她不是渤的门客；
- 她的网络不接受渤统一调度；
- 两人的吸引首先来自职业尊重与边界摩擦；
- 不在Y4提前预告未来孩子、软禁或悲剧终局。

### Y4相遇的场景因果
两人在天邑可以见面，但不能为爱情线硬造私密场所。

推荐因果：
1. 女商本来就要去见某位沧国旧客、合作商人或城主家代表；
2. 渤因青—沧贸易、港口关系或同一人物的政治价值，也本来就要到场；
3. 两人在一个**由第三方拥有的院落、宴后廊下、客舍会面处或学宫外的商人聚会**自然交叉；
4. 正事结束后，因为此前已有合作与私人吸引，才留下几句更私人的谈话；
5. 她提供的情报必须来自此前观察和网络，而不是为了这场戏临时“拥有一个万能货栈”。

原则：

> **先有各自的行动目的，再让两条线相交；相遇本身不是目的。**

# 17. Y4 死兽物证与灵台古史秘密（D113，旧引兽线废止）

## 17.1 公开目的：朔国以实证求援

Y4 北兽意外被捕获，**抵达天邑前已死亡**。北车运送的不是活兽或贡瑞，而是尸骸、兵器、伤口／工事证据及亲见北境惨祸的技术证人。**朔国要让天子与列国承认食人兽真实存在、灾情惨烈，争取粮械、军援及共同承担边防**。大朝会本已为朝觐、学宫及旧边费而召开，朔国之证使众人不能再将兽患视为谣言，却不能自动在 Y4 缔成天下联盟。

CH04 女史亲见尸骸与王都礼制的冲突并协助记档；CH05 终楠继续提供实证和工程判断，并可由伤口、旧史、古代兵器及金石线索推动探询八百年前怎样伤兽，**不得把 Y7—8 主矿发现和工法验证提前到 Y4**。

## 17.2 兽首仍是秘藏物证，不是攻城机关

公开检验可有爪、甲、骨、伤痕和兵刃。按 D30，兽首在验视后由王庭旧制的**灵台**秘密保存。这样既能有深远的古史与王庭禁异意味，也能让天邑灵台保章参横与太史伯策保有真实的政治／史料作用。

**D29：太史伯策为少数知情者，女史 Y4 并不自动知晓全部**，须凭师承所提供的旧档入口及自己的辨证推理逐步发现。参横可以行真巫仪，产生史籍和政治后果；但**巫仪没有可以吸引或镇压全部北兽的能力，旧“镇压失败致围城”因果已由 D113 废止**。灵台保管兽首一事，不强制在天邑围城情节中回收。

## 17.3 Y20—21 天邑之围完全不因兽首发生

**兽首没有远距或局部吸引、感应、定位、召唤、号令、改变兽群路线的能力。**幸存后代不会循遗骸找母亲、攻城复仇、夺回兽首；毁掉、移动或施法封禁兽首，也不会影响围城。

Y19—21 南压、Y20—21 单冬围城由北兽自身生态、寒季猎物分布、草原迁徙与少量萨巫有限诱导、列国战争与假和平削防、王畿河谷道路／粮道、城郊人畜密度等因素独立造成。**北兽并不知道天邑是王都。即使 Y4 没有运送兽首进城，围城也应可成立。**王畿实际路线需按地图与围城章合同校验。

## 17.4 母兽后代长线：学习与旧伤

Y4 成年雌兽至少有一头幼年或亚成年后代逃脱。它在此后十六至十七年间于草原、边境经历人类工事、火、弩箭与陷阱，成长为经验丰富的高阶兽；能影响邻近活体猎群，但**不是统一兽王**。它可同其他兽群一道进入 Y20—21 战区，但**绝不以母兽兽首为目标**。

Y24 终战中青鸾参与北线终杀，左肩白瘢、嵌 Y4 旧镞的证据照旧回收：这是**长期人兽战争留下的伤与记忆，不是寻母复仇**。

## 17.5 小说称谓与古典来源

正文叙述和普通对白主要称「食人兽」「北兽」；「狍鸮」仅偶见王庭／军政正式文书、内部世界古籍与学宫验典。**CH13 验出古名后，仍不改全书日常称谓**。现实《山海经／北山经》及电影饕餮仅是设计参照，小说中的古典应有内部虚构书名。

# 21. 首批样章三道验证门

## Gate A｜小说性
不读Bible，是否仍然好看？

重点看：
- 人物进场是否自然；
- 是否有阅读动力；
- 是否存在具体目标/冲突；
- 是否避免百科全书介绍。

## Gate B｜人物性
人物是不是活人，而不是理念标签？

重点看：
- 渤是否只是“人脉大师”；
- 骥是否只有“制度”；
- 菖是否被提前写成未来大人物；
- 铎是否只有“人情”；
- 其他公子是否真实有才华；
- 老一代权臣是否压得住场。

## Gate C｜结构性
Y4是否值得占5章左右？

重点看：
- 前两章是否需要；
- 人物是否过载；
- 信息是否重复；
- 第13章转折是否足够晚；
- 失简/情报/联姻是否抢戏；
- 是否真正做到“世界很大，小说很紧”。
