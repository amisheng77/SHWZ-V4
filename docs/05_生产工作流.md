# 2. 四种事实必须分开

正文创作时严格区分：

1. **Author Truth**：作者层面真实情况；
2. **Story Fact**：正文中确实已经发生；
3. **Character Belief**：某个角色相信/怀疑的版本；
4. **Historical Record**：后世档案、官方史、民间传说中的版本。

尤其暗线事件不能把“角色怀疑”自动升级为“作者真相”。

# 3. 写前流程

每一章正式写作前：

1. 读取 `SHWZ_Current_Context.md`；
2. 读取当前 `SHWZ_Story_State.md`；
3. 读取本章对应POV档案；
4. 读取本章所在时间线范围；
5. 读取直接相关专题；
6. 读取 `docs/05_生产工作流.md` 中与本章有关的伏笔；
7. **素材打捞**：按合同"素材引用"栏从 `research/` 素材库取 ≤3 条机制，蒸馏为素材卡（进 pack v2 的 Doc A）——不整库进上下文；
8. 创建 Chapter Contract；
9. 通过 Anti-Hallucination Gate 后再写正文。

不需要每章把全部世界观塞入上下文。

原则：

> **只读取本章需要的Canon，但一定先读。**

# 4. Chapter Contract

每章开写前至少锁定：

- 章节编号/暂名；
- 时间；
- 地点；
- POV；
- 本章开始状态；
- 本章必须发生；
- 本章不能发生；
- 本章人物知道什么；
- 本章人物不知道什么；
- 本章至少推进的两项功能；
- 人物弧变化；
- 需要埋/回收的伏笔；
- 本章存在理由。

**素材三层嵌入法**（素材引用栏的使用规则）：

| 层级 | 借什么 | 形态 | 例 |
|---|---|---|---|
| **场景层**（最常用） | 礼制、器物、流程、行话 | 直接构成场景质感——让读者**闻到**战国 | 学宫辩难如何立题、门客分几等餐食、使者如何呈国书 |
| **机制层** | 权力与人的反应模式 | 化入**原创人物的原创决策** | "冯谖市义"的机制→渤的周急养望（已入 Bible）；"二柄"的恐惧→青王忌渤 |
| **反用层**（最高级） | 读者的历史预期 | 借预期当背景板，前景走原创 | 铎有信陵君式社交人格，献城时刻的抉择却反门客逻辑 |

铁律：**拆机制，不抄桥段。**判据（换皮可辨认度测试）：换掉国名人名后读者仍能认出"这是某典故"＝抄，重写。素材库文言原文不得直接进正文（古代语境翻译门同样适用于素材）。

# 4.5 Pack 结构规范 v2（三文件分工，2026-09-26）

> 病灶（CH011 pack 实测 1600+ 行）：单文档巨无霸；指令/数据/参考无分工；**未做知识边界过滤**（含人物终局与未来弧——剧透即 foreshadow 漂移源）；canon 散文整段复制、检索成本高。
> 对标 analyzerpro step1：每章必读 3 文件、强制顺序、数据结构化。

**每章 pack 拆为三个分工文档，写手按序读取：**

| 文档 | 内容 | 弹性预算（行） | 性质 |
|---|---|---|---|
| **Doc A 写作手册** | 本章存在理由＋必须/不能发生＋Voice Card＋素材卡＋禁忌词表（global forbidden words 展开＋本章专属）＋结尾要求。由合同**蒸馏**生成（去状态记录类字段），不是合同复制 | 60—260（通读装脑，必须精） | **写手通读、全部装脑**——写作中不再回看也可以 |
| **Doc B 设定卡** | 本章出场人物**截至本章**的状态/关系/行为模式＋场景地理、礼制、器物事实＋知识边界表。从 03/06/08/02 按**合同知识边界节过滤**抽取，结构化列表而非散文摘录 | 120—700（重人物/大会章自然偏长；超上限才告警） | 备查——写作中按需检索 |
| **Doc C 专名与前情** | 本章专名表（registry 摘录＋称谓规则）＋前章 Delta＋相关伏笔 2—3 行 | 60—350 | 写作中随手查 |

> 预算由引擎 `PACK_BUDGETS` 常量单一源控制（区间内 ✓、仅超上限告警）；特殊章型调常量，不写死在流程里。

**知识边界过滤器（本规范的核心铁律）**：晚于本章时间点的一切 Author Truth（人物终局、未来弧、暗线真相、跨年代反讽）**不得进入任何 Doc**。终局信息只属于 00—14 原档与审计层。

**分工红利**：写手读蒸馏档，审计读原档——L0 用合同全文、L1/L2 用 canon 原档对照。**写手上下文干净，审计基准完整**，两头互不妥协。

**执行路径**：CH012 起以本规范手工编译三文件试点（pre-engine pack 照此）；格式经 CH012—013 验证后，固化进 nc 引擎（pack schema v2）。

若“本章存在理由”无法用1—2句话说清：

> **先不写。**

# 5. Anti-Hallucination Gate

开写前检查：

1. 是否新增了没有来源的国家/制度事实？
2. 是否新增了没有确认的亲属关系？
3. 是否让人物知道了不该知道的信息？
4. 是否把Proposal写成Canon？
5. 是否为了方便剧情违反神异/乌金/地理/制度规则？
6. 是否让非POV人物突然被全知读心？
7. 是否把人物后期性格倒灌到青年时期？

# 17. 正式逐章创作前的三项前置Gate

在稳定进入逐章生产前，必须优先完成三项小说化验证。

## Gate 1：关键场景压力测试

目的：

> **验证小说是否真的“活”。**

使用约6—8个代表性场景检查：
- 人物生命感；
- POV声音；
- 阅读动力；
- 三层文本自然度。

**当前状态：已锁定，但按作者指示稍后开展，暂不执行。**

## Gate 2：Character Humanization Pass

所有核心人物必须补足：
- 私人欲望；
- 羞耻/弱点；
- 不理性偏爱；
- 嫉妒/恐惧/虚荣；
- 无剧情功能的快乐；
- 至少一次违背长期逻辑但符合人性的选择。

目的：

> **避免“设计正确的人物”变成主题棋子。**

## Gate 3：核心故事单元与章节骨架

先将 Y0—Y25 历史凝练为核心故事单元，再依 `docs/04_章节骨架.md` **V5.3 暂89章**分章；CH42 仅在作者批准后可拆为90章。

每个故事单元必须回答：

1. 谁想做成什么？
2. 什么具体事件阻止他？
3. 哪个POV最适合？
4. 谁发生不可逆变化？
5. 删掉后全书损失什么？

只有通过这五问的历史节点，才优先获得正文展开资格。

## D103｜创作宪法三律 Gate（最高优先，不得被旧 Gate 冲淡）

**所有重大人物／战役／神异章合同，先回答三件事**：

## D99—D101｜第一性原理优先的创作门（取代“风险先行”偏序）

**创作流程在校验之前**：
