1. **一条资产≠一句摘要**：如焦获君主动求见必须有其动机、阻力和选择；不能只给他一个场面名字。如仲符战略警觉须**CH04看见兽体后**发生。
2. 每个章节群应先从旧文档和现行Canon建立资产表，列出**原出处、谁主动、原戏剧功能、新位置、状态、实际场景兑现**；未经作者批准不得静默删除重大资产、误将伏笔合并为一个万能谍网。
3. 只迁移仍有效的戏剧资产，不回滚旧CH02兽体即到、CH03—04倒闪、兽首引兽、子易学宫旧生、杜若情报属官、“荆国新任令尹”替代原相国。
4. 这是一份**场景迁移保障表，不代表正文已落实**；“后移待核”必须在CH06—15开始前继续清点和核销。
