# ═══ 卷一：地理 ═══

# 一、一级地理总纲

整个天下以中国战国地理为基本参照，但河流走向、国家边界、海域和部分山系经过重新组合。

- **西部**：极寒高原—西海—雍国西部高山草甸与河谷。
- **北部**：草原—朔国北部高地—朔国南部平原—北海。
- **中部**：河水东西主轴—河/梁/岐旧并国体系—王庭—文国。
- **东部**：青国大平原与丘陵海岸—北海/东海。
- **东南**：湄、峤缓冲带—沧国山海经济带。
- **南部**：荆国三大独立南流水系—百越山地—沧国海岸—南海。
- **西南**：荆国西南山地继续进入类似云南地区的部落与山地小邦世界。

# 二、核心地形

## 2.1 极寒高原

位于天下西部和西北部。高寒、人口稀少，但并非绝对无人区，存在高原牧民、盐路、山口贸易。高原东部有大型高原湖泊——**西海**。

## 2.2 雍国

大体类似现实陕西加甘肃东部，后期疆域扩大。

- **西部**：高山草甸，适合畜牧、养马、牛羊与边地部族生活。
- **北部**：高地和山地，拥有优良铁矿，是矿业与军工原料区。
- **中南部**：河谷和平原，为主要人口、农业与政治核心区。
- **南部**：大型东西向山脉，与荆国主体大部分隔离。
- **东南部**：可通过缓冲国进入荆国东北方向。
- **东部**：进入河、梁、岐、王庭与河水走廊，是后期扩张主方向。

> 北部高地属于雍、朔境内地形，不是境外单独地理带。

## 2.3 朔国

类似现实燕国加赵国一部分。

- **北部**：高地、牧区、边塞、军马基地和饕餮前线。
- **南部**：农业平原，拥有粟麦农业、城邑、粮仓和真实人口纵深。
- **东南部**：直接与青国接壤。
- **东部**：有一个沿海缓冲小国，早期可受朔控制，是朔的重要海上窗口。

战略弱点：

> 北部高地、山口和人工边防是主要第一道防线。一旦突破，南部虽仍有纵深，却缺乏第二道同等级天然屏障。

## 2.4 青国

类似现实齐鲁。

- **西部**：广阔平原，北方最重要粮食生产区之一。
- **东部**：丘陵、盐场、港口与海岸经济。
- **北部/东北部**：临北海。
- **南部**：经湄、峤等缓冲国进入沧国方向。

青国具有“大陆农业大国 + 海岸贸易大国”双重属性。

## 2.5 荆国

以楚国为历史基底，但地理结构重构。

整体：

> 西、北、东多山；南向南海开放；三条彼此独立的大型南流水系构成三个政治经济区。

- **西部**：山区，再往西进入高原南缘和高山—盆地—河谷区。
- **西南**：类似云南地区的部落、山地小邦、多族群区域。
- **北部**：东西向山系，与雍主体交通困难。
- **东北部**：有重要缓冲国，是通往王庭与中原的重要陆路开口。
- **南部**：三大水系分别入南海。
- 气候炎热，水患频繁。

## 2.6 沧国

类似现实福建加浙江。

- 内部多山；
- 沿海经济高度集中；
- 天然优良港口众多；
- 东海有大小岛群；
- 西部山脉与百越接壤；
- 北部与青之间有1—2个缓冲国；
- 西南靠近荆国东部水系入海口。

沧是典型山海型国家，不是农业腹地型国家。

## 2.7 百越

位于荆、沧之间的山地带。

> 东西两端都应收窄，不得膨胀成南方中央的大面积整块国家。

- 北高南低；
- 北部密林；
- 中北部为巨木主要产区；
- 中西部山区为乌金主矿区；
- 南部逐渐过渡为丘陵、河口与海部落；
- 有小型河流通向荆、沧与南海；
- 西侧靠近荆国东部水系和东部大封君领地。

# 三、主要水系

## 3.1 河水

**河水**以现实黄河为原型，是完整的西向东大陆主河。

> **西部高原 → 雍国 → 岐国 → 王庭 → 文国 → 青国 → 入海**

功能：
- 粮运；
- 铁器运输；
- 商贸；
- 军队与人口移动；
- 王庭交通；
- 东西政治轴。

河段：
- **雍国上游**：部分河谷狭窄、水急，水陆运输并重。
- **岐—王庭中游**：航运明显改善，为大宗河运核心。
- **文—青下游**：河宽、航运发达，同时存在洪水、泥沙与治河压力。

## 3.2 北部重要支流

> 北部高地 → 河国旧地 → 梁国 → 岐国 → 河水

这条支流是旧并国河谷体系的重要地理基础。

## 3.3 朔—青支流

自朔进入青国并连接河水下游体系。

功能：
- 青援朔粮运；
- 战马南运；
- 商贸；
- 难民迁徙；
- 饕餮潜在南下通道。

## 3.4 雍国内北南支流

> 北部铁矿区 → 中南核心区 → 河水

是雍国军工、仓储、工坊和国家化的重要内部物流轴。

# 四、荆国三大独立水系

> 三条水系必须彼此独立，不得在地图上合并为一个共同流域。

## 4.1 西部水系

以珠江体系为参考。

- 上游分成两大主要支流；
- 两支流分别对应强大地方封君（**岵阳君**＝上游支流，堤与巨木；**南浦君**＝中下游支流，仓与河运——D34 地理钉）；
- 下游汇合形成大型三角洲；
- 洪水频繁；
- 泥沙、浅滩、航道变化较多；
- 缺乏顶级天然深水良港；
- 是荆国最大粮食生产区之一。

政治上，水利、堤坝、分洪、粮仓、航道和漕运成为两大封君与王权冲突的现实基础。

## 4.2 中部水系

以湘江体系为参考。

- 独立南流；
- 荆都位于中游；
- 是王室最直接控制的核心流域；
- 入海口拥有荆国重要港口；
- 港口条件仍弱于沧国顶级海港。

## 4.3 东部水系

以赣江体系为参考。

- 上游靠近百越；
- 中上游与荆国东部大封君（**云阳君**）联系紧密；
- 靠近乌金矿区；
- 独立南流入海；
- 河口流量小于西部大水系；
- 附近有荆人与百越河海部落长期混居或直接接壤。

# 五、四海

## 5.1 北海

参考：

> 渤海 + 黄海北部 + 向东北延伸的寒带海域

沿岸：
- 朔东缓冲国；
- 青北部；
- 域外寒带地区。

特征：
- 寒冷；
- 季节性风浪；
- 渔业；
- 北方沿海运输；
- 寒带贸易。

## 5.2 东海

覆盖：

> 青国南部 → 峤国 → 沧国中北部

是天下最繁忙成熟商业海域之一，也是青沧海权竞争主要战场。

贸易：
- 丝绸；
- 陶器；
- 盐；
- 粮食；
- 港口中转；
- 海盗与私掠。

## 5.3 南海

覆盖：

> 沧西南 → 百越南 → 荆南

并继续向西南域外延伸。

主要连接：
- 南海诸国；
- 锡；
- 象牙；
- 香料；
- 珍木；
- 药材；
- 珠贝。

荆三大水系均南流入南海，因此荆有海贸，但远洋和港口体系弱于沧。

## 5.4 西海

不是外海，而是极寒高原东部大型高原湖泊，类似青海湖。

功能：
- 盐；
- 牧业；
- 迁徙；
- 祭祀；
- 姜/羌部落；
- 羌巫传统原生区域。

## 7.3 湄国、峤国（原工作名"淮、吴"，2026-09-26 C2 改定并锁定为正式两国；避真实吴国/淮河撞名）

位于青、沧之间，有河流自西向东入海。**青—沧之间缓冲＝两国**（数量已锁，D34）。

> **湄掌上游，峤掌河口。**

# 八、Y4人口—面积—经济基准

以青国为基准：

- 人口指数 = 100；
- 青国人口约 = 500万上下；
- 面积指数 = 100；
- 综合经济发达度指数 = 100。

“综合经济发达度”综合农业生产率、手工业、商业化、城市化、基础设施、交通、货币信用和市场整合程度，不等于总GDP。

| 国家 | 人口指数 | 约人口 | 面积指数 | 经济发达度 |
|---|---:|---:|---:|---:|
| **青** | 100 | ≈500万 | 100 | 100 |
| **朔** | 60 | ≈300万 | 80 | 60 |
| **雍** | 80 | ≈400万 | 120 | 75 |
| **荆** | 120 | ≈600万 | 200 | 70 |
| **沧** | 50 | ≈250万 | 90 | 100 |
| **王庭直属区** | **12** | ≈60万 | 15 | 110 |

> **百越不纳入此国家级指数表是有意为之**：Y4 的百越是多部族山地共同体，没有统一户籍、财政与常备军。需要量化时应按矿区、河谷或山盟相关区域做局部估算，避免伪造一个并不存在的“百越国家总数”。

# 十一、天邑人口修正

当前基准将王庭人口指数从此前暂估20下调并锁在：

> **12左右**

即王庭直属区约60万人。

其中Y4天邑城：

- 常住人口约18—22万；
- 大朝会期间临时人口明显上升。

天邑不是百万巨城。

其脆弱性来自：

> 对外部粮食、燃料和基础物资依赖极高。

因此后期“天邑之围”可以通过切断河运和陆路形成窒息，不需要真正攻破城墙。

# 十四、各国军事文化

## 雍：陆军—军工型

核心：

> 路修到哪里，军队就能到哪里。

强项：
- 步兵；
- 弩；
- 军械标准化；
- 工兵；
- 攻城；
- 后勤；
- 中等偏强骑兵。

**没有海军。**

## 朔：骑兵—边防型

核心：

> 人在马上，城在北边。

强项：
- 骑兵；
- 侦察；
- 快速机动；
- 边塞；
- 野战；
- 御兽；
- 防御工程。

没有成熟海军。

## 青：综合型

- 大规模步兵；
- 不弱骑兵；
- 河流水师；
- 北海与东海舰队；
- 强粮运与财政。

Y4综合战争能力第一梯队。

## 荆：步兵—内河水师型

- 大规模步兵；
- 舟船；
- 水陆协同；
- 渡河；
- 河港攻防；
- 水网战争。

必须区分：

> 会在河里打，不等于会在外海打。

## 沧：海军型

核心：

> 船就是沧国的马。

强项：
- 舰队；
- 水兵；
- 船载弩兵；
- 登陆步兵；
- 港防；
- 岛屿作战；
- 领航；
- 造船。

沧当然存在骑乘用马和驿马，但：

> **没有值得单列的成建制骑兵军种。**

## 王庭：都城防御型

优势：
- 精锐禁军；
- 城防；
- 河港；
- 专业卫士。

弱点：
- 兵源少；
- 长期大战承受力弱；
- 无海军；
- 无扩张能力。

# 十五、荆国内部军力特殊性

Y4荆国不能把全国军力直接等同于荆王可调动军力。

存在：

- 王室直属军；
- 西部两大封君军（岵阳、南浦）；
- 东部大封君军（云阳）；
- 各地水师。

因此：

> **纸面总军力强，不等于中央动员能力强。**

后期削藩、水权、粮仓和河运国家化会改变这一点。

## 1. 位阶全序（从高到低）

1. 天子 / 太子
2. 国君 / 国太子
3. **封君兼公子**（双重身份者，高于一般公子）
4. 封君 ≈ 公子（同级基准）
   - 年齿为次级因子：**年轻公子必敬年长封君**（CH012 裁决实例：骥[公子]见渤[北海君·封君·年长]——骥先下车、先见礼、称官称）
   - 国君直系公子 > 其他王族公子
5. **世子**：封君与公子之继承人；大城主之继承人亦可称世子
6. 卿（即上大夫）> 中大夫 > 下大夫 > 士 > 庶人

## 2. 官职体系（对照周制）

- 六官正职皆**正卿（上大夫）**：太宰（天官冢宰·治官统百官）、大司徒（地官·教/土地户籍）、大宗伯（春官·礼/王族事务）、大司马（夏官·军事）、大司寇（秋官·刑法）、大司空（冬官·工程）
- 六卿副官称**中大夫**：小宰、小司徒、小宗伯、小司马、小司寇等
- 再次为**下大夫或士**：宰夫、乡师、肆师、军司马、士师等
- 即：卿本身也是大夫，上大夫为卿
- **首席行政官**：列国一律称**相国**；王庭称**太宰**（与六官体系吻合——太宰即天官冢宰正职，统帅百官辅佐天子）
- **行政区划与地方官制**：北方行**郡县制**，南方行**州县制**；郡/州主官称**太守**，佐官**长史**，武职**郡尉/州尉**；县主官称**县大夫或县令**，武职**县尉**。**其余地方官职模糊处理、不细列**（防写作抠细失焦；与既有"雍国北郡籍/北郡大夫"用例自洽——雍朔居北行郡，荆沧居南行州）
- **史官体系**：**太史**为史官之长（王庭诸史之核）。人物关联：女史帧师承太史（与 CH011"老师"吻合）

## 4. 称谓用法规范

- **自称**：对话中报单名（"献""易"）；自称用"子X"即失礼
- **他称/敬称**："子+单字"是他称或书写体；对方知名后客气时升级（"子易兄，这边请"）
- **国别**：自报用"X人"（雍人/青人/岐人）；"X国"仅用于政治实体、籍贯官职归属（雍国北郡籍；家父为雍国北郡大夫）与第三方指涉（岐国的车马）
- **官称**：对有封号者称官称（北海君），优先于名字；近者方称"公子"；官面文书用封号；书写体叙述不限

## 5. 礼数动作规程

- 路遇礼序：位低者先下车、先见礼、称官称；受礼者可还半礼，**多还一分是受礼者的规矩**（非对等义务）
- 门外礼与门内例成对照：**学宫门内不称爵**（旧例压平门内礼数）——结构保留，正文可自觉利用

- **出席资格原则（D35）**：大会/朝会级场合出席者限**权臣／公子／封君**（＋世子随行），其余皆随员；同国内部对立阵营不同台（Y4 雍团＝仲符＋骥，毕原君/公子斯不出席即此例）

- **他称/敬称**："子+单字"为他称或书写体；对方知名后客气时升级（"子易兄，这边请"）

- **官称优先**：对有封号者称官称（北海君）＞名字；近者方称"公子"；官面文书（席次单）用封号；书写体叙述不限
- **女子**：自称单名同男链；有职者称官职（女史／女商），无职贵族女性随父/夫位阶虚写
- **姓名层**：单名＝中高阶层，双字＝平民（百越阿前缀例外）；姓氏非特别需要一般忽略，正文只用名

### 位阶全序
天子/太子 ＞ 国君/国太子 ＞ 封君兼公子 ＞ 封君≈公子（年齿次级：**年轻公子必敬年长封君**；国君直系＞其他王族） ＞ 世子 ＞ 卿（上大夫） ＞ 中大夫 ＞ 下大夫 ＞ 士 ＞ 庶人

### 六国爵位（国格，仅国际场合：会盟座次/国君称谓/外交文书；不作重点，以官职为主）
朔＝公｜青＝公｜雍＝侯｜荆＝侯｜沧＝伯（立国晚国君弱）｜河/梁/岐＝后封伯；余小国伯或男

位低者先下车、先见礼、称官称；受礼者可还半礼，多还一分是受礼者的规矩（非对等义务）；学宫门内不称爵（旧例压平门内礼数，与门外爵序成对照）

# 二十八、一句话定位

- **青**：腹地养人口，海岸养财富。
- **雍**：把矿、路、粮和人变成国家能力。
- **朔**：南方养北方，骑兵守天下北门。
- **荆**：天下最大的资源体量，却长期困在流域与封君之间。
- **沧**：船就是它的马，港口就是它的道路。
- **天邑**：失去军事实力之前先成为天下中心，失去天下之后城市仍然活着。
- **百越**：控制山地资源和上游，却始终拒绝被任何一个大国完全定义。
