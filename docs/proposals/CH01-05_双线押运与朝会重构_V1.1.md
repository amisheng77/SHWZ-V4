# 《山河无主》CH01—05 双线押运与朝会重构 V1.1（D118）

> 2026-10-21｜继承 V1.0／D117 前五章顺叙双线骨架。本文件专门补正“押运决策权”与“朝会证据之争”。未更改89章总结构、旧 CH011／CH012 锁稿及其哈希；正文、最终分场台词均尚未写成。

## 一、作者确认的权责结构

CH01 朔境意外困获成年母兽，先有捕获，**后有押送天邑之议**。终楠只是边镇工师，**无权自行决定远送、征用军车和调动押兵**。

现场由**边镇军官与文吏**依职掌共同讨论、形成押运决定。军官承担军令、军车、兵员和护送安排；文吏核对既有授权、记载重大物证、办理粮草与车辆凭信、封记及沿途交接，并承担其法定责任。两人可以有不同意见，不是工具化陪衬。

**右将军焦获君在此时已经抵达天邑大朝会**，他是当地军人必须呈报重大证物的实际军事上级。军官在争议中提及焦获君过去曾有“一旦得到足以核验的重大兽证，即刻报告／解送本人”之类常备命令，**属于值得优先使用的〔P〕剧情桥段**；该令是否书面存在、原句及现场签押者暂不定。不可因此倒写成焦获君预先策划抓兽、朔王远程瞬时下令，或终楠直接命令出车。

**终楠的高光**在技术：整兽过重难以疾行，任其腐坏会失去举证力，解体又可能被质疑拼兽。他提出先量绘伤痕、分段标记、两至三车装载、保存头冠爪骨与可证明同兽的凭据；真正发出车队军令的是军官，文吏记录与验核。运送最少十日，腐坏、疑疫、道路承载均产生实害。

## 二、天邑朝会“有报无物”的实质辩论

**CH02｜举证门槛**。朔国使团不是毫无证据：先前已有边境军报、伤亡资料、军士与百姓证词。然而其他使节**没有足以当场由诸侯共同核验的北兽实物**。有人因此提出尖锐、有经济与责任基础的反对：既有戍边费用之外，为何相信新兽患的独立规模、为何立刻增拨粮帛军械？不得将这位质疑者写成不信任何朔人死伤的蠢人。渤必须承认证据门槛真实存在，而非只靠口才把疑问抹去。

**CH03｜门槛升级**。争论从“究竟有没有异兽实物”升级为“谁负责核验、什么物证足够、尚未验明前可以承诺什么军粮和风险”；文国名辩子易以有效反诘显示才华，渤的政治智慧转化为具体行为。不要连续两章重复一样的唇枪舌剑。

**北车平行线的反讽**：恰在朝堂索求实物时，朔方军吏押着分解后两至三车证物日夜赶路，终楠正跟腐败、疑疫拒车、桥道载重以及封记损坏作战。读者知道物证在途，天邑朝议中绝大多数人还不知晓；也可以在后续章合同裁定是否有先行快骑军报，但**不能提前变成实物已经完成验真**。

**CH04｜碰撞与政治转向**。残存裂冠、骨皮、爪肢、原始丈量绘形与军吏封记、战地证人互相佐证：一头骇人的北兽确实存在，朔国绝非空口捏造。城外控制场所可以作为检验方式，不能无视疫疑将腐尸抬上王宫大殿。渤促成共同核验和有限的政治、运输及研究承诺；终楠是技术与第一现场活证；女史记录可核的证据链。**一头异兽确凿存在并不能独自证明朔国历年所有报损或请求的全部军费数额**；其他列国仍能依理核账，后续 CH11—15 继续论争，Y10—12 才有真正联盟。

**CH05｜兽弱与旧史**。从保存的硬组织、现场预先丈量记录和旧伤辨识中，终楠与女史分别提出中后腹侧等潜在薄弱部位与八百年前御兽旧史疑问；不提前发现主矿或成熟乌金战术，不把“止／伏”的史官笔法冒充失落上古英雄的大谜。

## 三、需留章合同的细节〔P〕

边镇军官与文吏具体姓名／军阶／官衔、实际发车签押方式、是否引用焦获君旧令与快骑是否先达、朔王后续如何获得报告；CH02 由哪个使团的人提出质疑、CH03 子易辩题与谁先支付何项费用、CH04 合规验兽场地与有限承诺条目；确切车数、分解方式、当日季节、腐败损失和天邑路程。**以上不是已经写就的事实**。
