## 1. 总体结构与新时钟

**核心人物：终楠＋公子渤；女史帧为次核心、独立史秘视角。**其他人物在天邑既定朝会中以有辨识度的行动短促亮相，不开新长期 POV。前五章全部为 Y4 时间向前的顺叙，**没有独立闪回**。

- CH01 朔境突遭北兽袭击，终楠救人并**意外**困住成年母兽；**捕获后朔国才临时决定**把兽及物证运往早已依期举行的天邑大朝会举证求援。不存在预先策划献兽、临时为兽召诸侯。
- CH02 与 CH03 **双线并进**：一侧是列国人物陆续入天邑、原有守边费／互市／朝觐议论；另一侧是押运北车从朔境出发，日夜赶路。**最短车程为十日**，并非 CH01 困兽、CH02 隔日入邑。
- CH04 北车**首次抵达天邑**，兽尸证物引发天下震动。渤以真实政治行为推动合法共同验兽、终楠实证，女史留有可复核史档。可以安排城外控制验场，不强令腐尸抬入王宫；Y4 仅能有有限承诺，真正御兽联盟 Y10—12 才成。
- CH05 根据有限保存的尸骸、押运前绘形量尺及现场证词，终楠提出可验证的克兽弱区／工法问题；女史发现八百年前御兽史料存在异文或缺环，**只是悬疑开启，不是失落上古英雄大谜揭底**。不得预支 Y7—8 乌金主矿及 Y11—12 成熟猎阵。

## 2. 车队的实质困难：两至三车、腐坏、疑疫、证据链

**设定已确认**：成年北兽庞大沉重，为尽快通过有限道路与桥梁，须沿关键部位分解后装**两至三辆大车**。分载可以减小单车负担，但全队仍受最慢车辆、牵畜、轮轴、桥路与驿站限制，不能自动大幅突破十日路程。

**分解与保存的两难**：完整巨兽更有视觉说服力却难速运；随意肢解则令列国质疑“拼凑不同野兽”，且尸体腐败速度较快。终楠的工程才能首次在此显现——**先量绘后分解、逐件封记、标明原战伤与人为分割刀痕、随车由军士与工匠交接见证**。优先保留辨识度高的头冠、颈肩骨皮、背脊硬皮、四肢巨爪与伤道残件；车数、分割精度与负载仍〔P〕。不要求天邑将巨兽拼装得像活体。不能让大量软腹组织十余日后依旧新鲜。

**腐坏与疑疫**：古代可尝试清除脏污、有限盐渍、阴凉遮护、隔离封载，但必须承认其保存局限与物料成本。行经驿站、县邑或城门时，地方官与百姓担忧臭气、尸液、污染和疫病，是**合情合理的阻力**，不是无脑恶官；押运者应选择弃去失去价值的组织、补封／改道、城外查验等有代价的办法。**“怀疑可能造成瘟疫”不等于北兽已被证实携带瘟疫，更不是北兽的超自然能力**。不得凭尸骸招来兽群、幸存幼兽追母或兽首吸引兽群。

**责任链**：焦获君为朔国已在天邑的使团首席时，不可能同时身处朔境捕获现场；朔国临时发令者及军报/驿递时序按正文合同核查。北海君渤不能代替焦获君的朔军权或成为终楠直属军政上司。

## 3. 五章执行分场

### CH01｜朔境兽袭（旧《夜哭》标题是否更改待定）｜终楠主 POV

1. 白昼牧场／边寨遭迅猛异兽猎牛马，守备失措，人畜伤亡真实。
2. 终楠先救人，凭现场旧工事、地势与众人牺牲，**意外**困住重要成年雌兽；至少一头幼／亚成年后代逃脱，Y24 遗镞白瘢链不变。
3. 捕获后才意识到这是迫使列国正视北境食人灾难的难得证据；朔方临时商议押往天邑。
4. **章末钩子**：他们终于证明了兽的存在，却发现巨兽根本难以装车或保鲜。不得因为章名《夜哭》把主要捕猎改回夜间。

### CH02｜天下来客／三车启程（暂名）｜公子渤主 POV，终楠短窗

1. 天邑：列国朝觐／学宫祭酒大会按既有计划准备，渤围绕朔雍旧边务、互市与谁承担费用有明确行动和阻力。使者随事亮相，不读人物卡。
2. 北境：兽已死或临出发时死，朔方对保全尸体与能否远运发生争论；终楠建议事先丈量绘形、分解为两至三车、保留头冠爪骨与真实伤痕，承担证物可信的风险。
3. **章末钩子**：车队终于出发；同一时间，天邑的诸侯仍在为旧问题争论，尚不知道真正的异兽证据正在靠近。

### CH03｜北车南行／朝议未定（暂名）｜女史主 POV，终楠短窗

1. 天邑：女史整理旧边报、朝会简册，发现一条值得核查的断简或异常记载，而非直接破解失落英雄大谜。
2. 朝会：渤的目标继续受阻；**文国正式使团中的子易**用一次足以影响辩论走向的反诘显示名辩才华，被渤识赏。仲符、骥等有锋芒但不设独立主角回合。
3. 沿途：在至少十天行程中**重点展示一次**腐坏／疫疑拒驿／过桥载重等高价值冲突。终楠以工法、承担责任、损失部分无法保存的组织换取继续通行，不能十日流水账或连续套路拦路。
4. **章末钩子**：证物究竟能否在腐败到无法查验之前送到天下面前？女史此时尚未见兽，北车仍未抵邑。

### CH04｜天下震动｜公子渤主 POV，终楠现场证词、女史经窗

1. **至少十日后**两至三车首次抵达天邑。腐臭、裂冠与巨爪令人震怖；城门疑疫拒入不是愚行，腐尸不必搬入朝堂。
2. 渤发挥真正的身份、信用与识人能力，促成朝廷及列国代表在合法受控场所共同验兽，不能凭一句话就造 Y4 御兽联盟。
3. 终楠逐件核对原始量绘、封记、旧伤与切口，说明为何来自**同一头成年食人兽**，以朔境真实死伤作证；女史负责记档、保存证据可追溯性。
4. **阶段胜利**：天下正式认同朔境兽患不只是传闻，准许后续验察／有条件物资协助〔P〕；**章末钩子**：看见怪物，不等于知道如何战胜怪物。

### CH05｜兽秘初现（暂名）｜终楠主 POV，女史经窗

1. 检查能保存下来的骨皮、爪、头颅与出发前测绘、旧伤记录；不能重新取得已丢弃腐坏的完整软腹。
2. 终楠提出食人兽**中后腹侧、后肋下缘可能较薄弱**，头部迅猛使普通弓手射眼不适合作常规方案；这只是可验证的思路，不是立刻掌握“教错它”成熟战法或乌金深刺神效。
3. 女史透过内部虚构古籍、残简或旧铭发觉八百年前御兽知识或被删失；“止／伏”是春秋笔法一字异文，不足充当第一部重磅历史揭秘；上古失落英雄的壮举／遭抹去原因后续另案审定。
4. **章末钩子**：古人是否知道某种克兽之法？何以失传？Y7—8 乌金主矿发现不能提前。
