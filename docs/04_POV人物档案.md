# 1. 公子渤——第一男主、中心英雄

## 1.1 定位

> **孟尝君＋管仲**：对内好士、轻财、重诺、周急、养望，替王兄分忧；对外列国调解、恩威并施——不出一兵而屈人之兵。

他不是"网络型权力"的抽象符号。他名满天下靠两样东西：**让人愿意投他的门**（孟尝），和**让敌国在他的账本面前低头**（管仲）。

政治罪只有一个：**太完美，名望超过王兄。**

唯一保留的性格灰度（D7）：**恩变成债**——他不自觉地把施恩变成筹码；一生有过一次牺牲门客的越线事件（为保大局牺牲一个并非有罪、受过自己恩的人）。这不是道德污点，是他"大局"的代价。正因为有这一层，杜若"最懂他"才有东西可懂。

## 1.2 权力四支柱

1. **门客体系**：士人、剑客、商人、工匠、游士、亡命者、外国人——政治人才库＋外交网＋行动网。
2. **商业信用**：母族＋外戚＋王族港盐投资；海盐、仓储、粮食、航运、信贷、远洋贸易。核心认知：**钱不是财富，信用才是权力。**
3. **联盟财政机器**：成本分摊＋联盟信用＋粮运体系——他真正的代表作，Y24 胜利的底座。
4. **天子授权**：Y21 解围后任联盟实际统帅（明面盟主＝天子；"王印盖在渤拟的文书上"）。

## 1.3 签名战役（必须上页演示，不能追认）

- **衡山之谋（Y10—11，CH35—37）**：纯用粮价、信用与港运掐死一场小规模战争，青国一兵未出。
- **天邑解围的青援（Y20—21，CH69—72）**：围城之冬，他的信用机器把粮和军械送过冻结的天下——解围即巅峰。
- **云阳君绞杀（Y22，CH73—74）**：联盟经济封锁＋临风军事围困——他救了荆。
- **终战方略（Y22—23，CH75—77）**：纵深防御＋围猎＋乌金终杀＋联盟总体战的总体设计。他死后机器照常运转。
- **一场对雍的失败（盟/背之交）**：他用钱，骥用国家机器，机器赢——他挡不住雍梁战争，悲剧必需。

## 1.4 与青国王室

- **老青王＝渤王兄**（D4）。青国上一代三兄弟：老青王、邝之父（当年继承之争的失败者）、渤。渤置身那场斗争之外——这解释了他为何走"网络"而非"王位"的路。
- 兄弟模式：王定方向，渤解决问题。裂痕在于渤因"结果正确"越来越绕开程序。
- **新青王＝老青王之子、邝堂弟**（幼时共同成长）。老青王到死不敢动弟弟；Y22—23 老青王死，新王一继位即与邝联手发难。
- 邝的弧线：海战失利（Y6—7）→假旗揭底二次受辱（Y13）→**从竞争者烧成执刀人**。一句话对照：**渤用信用赢得天下，邝用嫉妒读懂青王父子。**

## 1.5 与杜若（详见 §2）

Y4 已识有合作 → 多年并肩 → Y16 决裂（她破坏他的越线计划）→ Y20—21 围城之冬她的网为他运粮 → Y23 他落，营救失败 → 她带着儿子和账本活过他。

## 1.6 终局：身后名

Y23 落：门客不得入府、商人不得直接联系、书信审查、学宫断资、网络拆解国有化。杜若营救失败——他拒绝以大规模牵连旧网为代价逃亡。

Y24 胜利按其方略到来；天下开始明白那台机器是谁造的。**他救了天下，被自己家国处刑；死后，世界用他的方法继续活着。**

渤海遗产三分：王侄邝制度化、杜若南方信息网、侠客行动网。

# 2. 杜若——双女主之一，青线接棒者

## 2.1 定位

> **守业、惜名、重信、知利。** "杜若"二字可以借钱、拿货、通港、做保——商人的名字本身就是货。

她首先是一个真正会做生意的人（看丝、谈价、算货损、认船期、识人信用），然后才是情报网。她的信息优势来自**正式政治人物看不到的流动**：哪个使团追加马匹、谁的账期忽然改变、谁在打听婚约、谁突然购买北境地图。

## 2.2 与渤

- 两人是**恋人＋盟友＋各自独立网络的拥有者**。她不是门客，不受他调度。
- 能力镜像：**他擅长看"谁应该连接"；她擅长看"谁在隐藏什么"。**她几乎与他一样会读人，却不被他的声望牵着走——这是他珍视她的底层原因。
- 她最早看见他的悲剧："你不能既做王的臣，又让天下所有人都欠你人情。""因为王也会欠你。"
- **Y16 决裂（她 POV 启动，CH53—54）**：梁危机中**铎遣使泣求**，青王不肯出兵；渤遂动用信用与粮网对雍经济施压逼停战——断战购、抬粮价、卡港运，代价是两国边市平民先饿；杜若泄掉"断粮闸门"那一件，行动失败。"什么也没有。""那你为什么？""因为你以前不会这样做。"——她背叛的是计划，不是感情。
- 有一名未公开的儿子（约 Y11—12 生），渤知道存在。
- **Y23 营救**：他落之后，她动用自己独立的商号、船路、港口关系全力营救，失败。
- **Y23—25 续账**：渤死后，他的机器还在转——因为她在转它。终战南方情报与粮运枢纽是她那张网；Y24 胜利里有一块是她扛的。终局关键词：**他死了，账还在走。**

## 2.3 乌金暗网

渤退场后她进入南方乌金地下世界——不是走私女王，是**信息经纪人**："乌金在哪里"的知识比乌金更贵。人物弧：**所有消息都有价 → 有一笔账明知亏也要做 → 有些消息根本不能卖。**

## 2.4 与阿瑶（双女主照面，CH63—64）

中后期乌金线上两人隔案对坐：**一个知道万物之价，一个知道万物之成本。**一场戏，不必多。

# 3. 阿瑶——双女主之二，山的女儿

## 3.1 定位

> **家、寨、亲族、祖墓、猎路、山场、水源、季节。**她不觉得自己在"保护百越"——她只知道那片林不能烧，阿公埋在那里。

成长三段："这是我们的山"（一个部落）→"这是我们的山"（山盟）→"山不属于任何一个人"。

## 3.2 与临风（详见 §4）

- Y7—9 探矿相遇（同级对等）→ Y10 洪灾情愫 → Y13—16 婚事将成 → 同一夜两次选择 → Y17—18 他来占领她的山 → Y19—20 决堤冻结 → Y22 平反 → 终战并肩 → **山歌私约＋终局留白**。
- 关系铁律：**对抗在前、动情在后、始终她族优先。**两人每次都在职责和对方之间选职责。

## 3.3 婚配三段机制（D8）

1. **资产锁定（Y7—12）**：她是活的矿图，嫁出去＝矿脉知识流出。父亲与长老主动拖延婚事。
2. **制度锁定（Y21—23）**：山盟需要她当中立中间人——嫁给任何一部＝那部绑架山盟；嫁给荆国主将＝山盟沦为傀儡。**她亲手建了保护百越的笼子，笼子也关住了她。**与"圣女"的本质区别：神权是别人强加的，这是她自己制度的代价，且她每天都可以选择打破——代价是山盟当天裂开。
3. **山歌私约（全书暗线）**：两人按百越口传规矩私下定情——无公文、无聘礼、不入名籍。**他们的婚姻以一首歌的形式存在**，也许只有女史那部秘密实录里记了一行，也许连一行都没有。

## 3.4 追求者线（D8/D14）

- 本地青年，完整的人：可靠、懂山、懂她家人、真的适合一起生活。输掉不是因为嫉妒，而是因为**他的世界跟他爱的人生在同一个人地方**。
- Y13—14 父亡后婚事将成；Y15—16 同一夜：他的族发动有荆国背景的袭击，他知情沉默（**然亲族之义重于情爱**）；婚事无疾而终。
- 她理解他为什么沉默。正因为理解，才回不去了。**此事她谁都没有告诉**——追求者至死不知道自己的沉默被拿去和别人的报信比过，临风也不知道那次报信在她心里值多少。只有读者看见全貌。
- 他不黑化、不退场：山盟时期作为本族代表与她共事多年，那件憾事是两人之间永久的安静的东西。

## 3.5 山盟与归山

山盟＝松散共同规则：外国开矿须经相关部落同意、不得永久转让矿权、巨木砍伐设上限、共同防御义务。她拒绝永久盟主："保护百越最好的方式，不是让一个正确的人拥有永久权力。"

终局：临风辞兵符出走后走进她的山（D17）——两人的婚姻以一首歌的形式成立，后记三个同框镜头收束。"以前这里全是树。"远处有年轻人在新划定的禁伐区种树。

# 4. 临风——荆国将军，智力天花板

## 4.1 定位

> **知兵、任势、受命、守土。**平民出身（北方工匠家庭/流民），墨者训练。战争观：**让一场本来会死很多人的战争，变成死得少一些、快一些的战争。**

修订（D 决议）：**拿得起放得下，不是患得患失的人。**他的道德挣扎不在犹豫，而在**速度**——他决定得快、执行得狠、代价算得清；他的人生问题是"我有什么资格替别人算这笔账"，而不是"我下不了手"。

## 4.2 晋升阶梯（D8 细化）

下级工程军官（Y7—9 探矿期，与阿瑶同级相遇）→ **洪灾危机处置**（Y10 前后：主持救灾、改道救援百越村寨、与云阳君结怨）→ 边境危机历练 → **削藩战前被荆王点为主将**（Y17—18；履历＝洪灾交手云阳君势力＋百越事务全荆最熟——荆王选他不是信任他，他是插进封君地盘最锋利的刀）。

## 4.3 与云阳君——全书最好的人反派对手

云阳君（荆东封君）：家门、封土、世守；**坏得有效**——洪灾迟报邻区、先救自家、灾后开仓反得民望。师兄为其将（双层对手：封君出钱出势，师兄出兵出工；同门分裂主题保留但降半档）。

对决横跨十五年：洪灾（Y10）→ 削藩战（Y18—22）→ **Y22 云阳君覆灭（爆点一）**：联盟经济绞杀＋军事围困，洪灾旧案曝光，**"通越"平反**。

## 4.4 与阿瑶

- 他一生唯一一次因私废公：**提前给她透了一个剿寨行动的消息**——这成为云阳君手里"通越"的铁证，削藩战中差点毁掉他。私德被政治审判，与渤的恩变债同构。
- Y19—20 决堤：他的军事决定直接伤害她的族——深度冻结。"你每一次来杀人，都告诉我这是为了少杀一点人。"
- 救赎即告别：终战南线条约保山盟条款（对抗荆国利益）——**他把选择还给她**。山歌私约在终战前后私下成立（无公文、无聘礼、不入名籍）。

## 4.6 终局：兔死狗烹的解法——功成身退，出走归山（D17）

战后他成了荆国最不可罢免的权力：亲手重建的军队、山盟的人望、条约的个人担保。而削藩后的荆王廷刚刚摧毁强人政治——制度容不下第二个云阳君，哪怕是自己造的。三要素：①**结构**：削藩后的王廷对"不可罢免的强人"零容忍；②**人**："通越"旧案被翻出新解（Y22 平反过的东西，战后变成"将军有自己的外国"）＋**渤之死的前车之鉴**（Y23，天下人都看见了功臣的下场）；③**扳机**：《乌金约》谈判中他保山盟条款对抗荆国利益——王廷终于确认必须动手。

他不等发难：**辞兵符、辞封赏、留军于将、悄然南去**。荆王如释重负，体面放行。全书唯一看破中央陷阱并全身而退的人——不是因为他更聪明，是因为他是唯一不想要那台机器的人。**渤之死教会他的，他从不解释**（终战中段听闻渤落，一言不发；胜利后即辞）。"拿得起放得下"在此完成最终兑现。

**山门为他开的条件**：阿瑶的制度锁（嫁荆将＝山盟沦为傀儡）因他**先辞去身份**而自然解开——他付清了门票，才走进她的山。终成眷属：全书不给婚礼，只在后记给三个同框镜头（见 07 骨架 U36），读者惊喜感来自漫长的分离之后的安静重逢。

## 4.5 军事风格

工程化投降：挪水、断粮、改路、拖时间——不战而屈人之兵。杀戮极少，仅有的狠手（决堤）才有千钧之重。

# 5. 仲符——雍国改革者

> **富国、强兵、立信、定制。**"仁是目的，法只是手段"——后人记得他的法，忘了他的仁。

- 儒法并学，母族青国见闻是政治理想源头；上一场雍朔战败（父责"人心坏了"，他答"等国家都是君子，国家一定输"）。
- 缺陷：固执、控制欲、过度相信制度理性、临时措施永久化。
- 与终楠：互相尊敬的对手——制度与手艺、标准与活的经验；起于 Y4 一笔错账的平账，**十五年私交全部写在联防公文页边**；朔北首捷是两人作品的第一次咬合；假和平期唯他逐页当真终楠的足迹报告（详见 §7）。
- 与骥：师徒＋精神父子。老师说"国家强大是为了让百姓不受欺负"；学生推演成"百姓不受欺负是因为国家足够强大"——**他在完成老师**。
- Y18 放逐（D1）：新官僚—新军利益集团清除，**骥默许**（不下令、不营救）。最后一面：仲符只求保学宫，骥准了。
- 终局：封地私学，教乡里子弟。终局意象：站在自己年轻时修的路旁，看标准化军械车队驶过——一生梦想的景象，他第一次感到害怕。**他的思想由骥继承并强化，他只是政治派系的牺牲品。**

# 6. 骥——雄主，非反派

> **功业、法令、赏罚、强国。**不是腹黑：亲守军令、可上前线、宗族犯法也罚、对有功者真赏。

- 储位竞争（Y10—14）：改革利益集团围绕他聚合——不是门客党争，是**新国家利益集团选择自己的主人**。核心变化：从相信制度，到相信只有自己掌权才能保护制度。
- 雄才事实支撑（必须上页）：军令自守、执法及亲、迁民功成（"十年之后，这里有雍人、有田、有仓、有兵"）。
- Y18 即位；**默许放逐仲符**——他没有杀老师，他继承了杀死老师的机器。这一层不解释，只压在行为里。
- 终局：政治最成功、道德明显退化、不必悔悟。第一部结尾他是新列国时代最强的陆权之主——**第二部统一故事的地基，但第一部不写统一**。

# 7. 终楠——朔国工匠

> **工法、成法、守器、师徒。**"它不是撞墙，它在试墙。"

- 雍国工匠之家因 Y-11 战后一笔冤枉的军需物料账外逃入朔（贪吏记亏欠——Y4 仲符平账，见下）；身份模糊（"我守的是会被吃掉的人"）；墨者老师指点（与临风同源传承）。
- **签名战役＝朔北首捷（Y11—12，CH41—43）**：人类第一次正面大规模打赢饕餮——他的"教错它"防御工程（墙是假的，弱点是喂的，杀阵在它以为最安全的方向）。前半季爆点，朔线实锚。
- 假和平中的孤警报："它们没有死，只是走了"——被胜利声淹没。
- 高阶饕餮＝专业对手：两套学习系统互相观察，不带人格化台词的"彼此认识"。
- **与仲符——制度与手艺（全书主题的化身）**：
  **Y4 认账（不是认亲）**：验兽场上仲符从年轻证人手法里认出雍地工脉，问其父名；当夜调档，发现父名在**欠项册**上——战时交还的军械物料被贪吏记为亏欠，全家因这笔冤账外逃入朔。而这笔账写在 Y-11 战争的仲符家封邑、**他本人督办的军需链上**：改的不是别人的错账，是自己链条上漏下的错账。他不施恩，他平账——销欠、补直。终楠只答一句：**"账对了，人回不去了。"两人关系的语法就此确立：制度能改账，改不了账造成的命**（仲符全书弧线的微缩预演）。
  **批注之交（十五年）**：此后无私信、无共饮、无称兄道弟——全部私交写在联防公文页边：仲符在申领单页边写问题，终楠在回单页边作答；官方纸上两人是供应链两端，页边上是彼此唯一的读者。假和平期"雍的买家里唯仲符逐页读完"正是这套协议的果实。
  合作本体经**计量阀门**进行，从不汇池：朔以战场数据与杀伤报告**偿付换取**雍之成品军械（有兵器，无工艺——不授炉温配比与工坊之法）；接口兼容靠联盟促成的**弩矢接口标准**（联盟极少数真公共品之一，天邑调停）。**朔北首捷＝仲符的制式箭头经接口标准装进终楠的"教错它"杀阵——两件作品在阀门两端咬合，而非两国共享技术**。雍方反间给他建档（用其图、限入核心工坊），朔方军中亦疑"雍种"——他两头被疑；页边之交是越过阀门的例外，也是唯一不被翻译的频道。分歧终身未解且另有妙处：**仲符想把页边问答编成制式规程——他连友谊都想标准化**；终楠抵制——"任何固定体系都会被学习"（饕餮教他的）。假和平期最具反讽的一笔：**朔把终楠的足迹报告当联防货卖出，雍的买家里唯仲符逐页读完**（卖家自己没人读）——雍因此保留北境投入，最大南压时是"第二受压但撑得住"的一方，朔被砍到骨头。最大南压期终楠以联盟工程专家身份巡雍东北防线（支援不迁居）。终局：**修桥用的是仲符制式标准件——两个答案在同一座桥上会师**（可选终笔：终楠归途绕道封地私学，不带礼，只带一卷旧批注）。全书直接见面仅三四次（Y4、首捷前线），余皆纸边。
- **情感线：关雪（朔边镇戍卒之女，D17）**——不是女将军，也不是将门之女：**父亲是 Y-11 雍朔战争带旧伤回乡的朔国老兵**（她因从小给父亲处理无人能治的旧伤而进伤兵营——医术起点是一笔战争遗产）；懂驿马、粮秣、伤兵、烽火、冬天怎么活；会军镇级实用医术（清创、缝合、夹板、冻伤、慢伤护理——不封神、不开宗、治不好自己）。**两家是同一场旧战争的两份账**：终楠之父因那场战争流亡入朔，她之父因那场战争带伤而归。五拍（戏少，每拍皆铰链）：①**U01 相识即救治**——CH1 边境事件终楠负伤（同行者死，他携物证活下来）；CH2 她在伤兵营主刀为他清创，他半昏迷还在描述兽怎么试墙——她的手先认识了他的伤；伤愈留营帮工相识，带旧伤的父亲问"雍朔再战你站哪边"。②**Y10—11 越线事件·公堂救名**——假和平削资致试推防线被提前启用、死人，军中追责"雍种"；她以伤口证据公开作证（伤道走向、破口时序、尸首位置证明非设计怠工乃仓促部署）；**公堂救其名，私下一句不赦免："不死人，谁知道这东西守不守得住？"——信任≠赦免**；死者化为"教错它"学说的第一块基石。③**成长功能：他的物理真相源**——没有她他会活成仲符（纯体系）；他后期"可修复、可替换、给普通守军用"的设计哲学出自她的伤兵营。④U29 她的军镇破城重伤——**医者变伤者**，他第一次站到清创台另一侧：他让别人付过的代价回了家（从修墙转向修桥的内在起点）；此后她带伤者的知识重做医者，专攻慢性伤口与残肢。⑤和解与偕老：她懂他为什么必须去修别人的墙（"那边墙破了，它们最后还是会到这里来"），他懂她的伤是他缺席的代价——**工程师的道歉方式：把家门重修成没有门槛的样子**。终局：修桥工地的工伤棚与粮秣营归她管；后记里铺子她在治学徒的手伤、管账。护栏：不升 POV；医术不接管剧情因果；她会收钱、记仇、冷脸——有脾气，不圣女。
- 终局：半生修墙的人最后修了一座桥（雍人、朔人、老兵、难民后代一起——那道曾被质疑"你站哪边"的雍朔旧边境，由两头的工人一起合龙），然后回边城修农具、带徒弟，与她偕老。

# 8. 女史——时间锚与记忆总线

> **史法、名实、直书、讳与不讳。**"何者当书？何者可讳？谁有资格改一字？"

- 天赋＝发现不一致（档案学侦探：版本、缺简、年份、措辞差异）。
- **师承（D29）**：她的老师是一位年老史官/旧档掌故者，曾接触王庭旧制封禁体系，是 Y4 兽首完整秘密封存的少数知情者之一。老师的功能不是替她公布答案，而是让她知道“哪一扇门存在、哪一卷旧档值得找、哪个旧称不能按字面读”；女史仍须靠版本比对、物证与时间链自己完成判断。由此师徒关系既提供解密便利，也保留她的有限认知。
- 麒麟线："止"改"伏"的一字之差；召麟仪式失败与天子开门纳民；麒麟只打断高阶共振，不替军队赢。
- 天邑之围（Y20—21）亲历者：记录一个拥有合法册封的诸侯如何消失（梁亡），再记录一座城如何在"有理由"的沉默里窒息。
- 终局：两部历史——公开史书绝不说假话、但不写某些东西；完整实录拆散存放。**最终亲手留下一处错误："不要改。"**她成为当年的老师。
- 女史史体第一部 10—15 组，必须提供正文没有的第二意义。

# 9. 舟月——沧国小 POV

> **船众、信誉、胆气、风信、航路。**全书约 4 章：蛟窗海战（CH21—22）＋海路联通（终战）。

- 蛟窗海战：以潮汐、鱼群、蛟活动概率创造窗口——利用环境，不召唤神兽。

- 终局：推动海路公共化（交权）——建立一项自己也不能无限占有的国家能力。海军国家化余下戏份留第二部。

# 14. 硬规则

1. 渤保持"近乎完美＋恩变债灰度"；骥是雄主非反派；铎终局自焚不洗白。
2. 阿瑶政治主体性不可侵犯：爱情永不软化百越抵抗。
3. 临风的狠手保留（决堤）；救赎＝把选择还给别人。
4. 追求者不黑化。
5. 不让七个 POV 都成为最高统治者；终局必须保持差异。
6. 人物首先活在名、义、信、恩、耻、功、爵、宗族、师承、宾客、封土、史法与身后名中（Bible V3.0）。
7. 骥第一次 POV 不回溯解释过去；杜若第一次 POV 自决裂写起。
8. **同线双 POV 纪律（临风×阿瑶）**：①同一事件只从一个内心写——决策写临风、后果写阿瑶，同一场景绝不双内心；②两人同场戏全书不超过 5—6 场，每场只开一个 POV；③领域隔离：临风 POV＝军中/工程/政治/云阳君线，阿瑶 POV＝山、寨、矿、歌、山盟——战争在阿瑶眼里是天气和灾难，不是战略；④共享单元（U10/U26/U28/U34）内两人各占不同章。读者持两半拼图，任一角色只持一半——CP 成立的前提是只有读者看得见全貌。
