# 第十一章 天下来客

诸国会于天邑的第一日，陆门比平日早开了一个时辰。

天没亮透，城外已排起车队。夜里先到的在道边生火，炊烟贴着地走。谁先入城，礼官的简上早写定了，可各家的傧还是天不亮就立到门下，谁也不肯比旁人晚半步。水门那边也有舟在排，橹声隔着雾一声一声，像在数自己。她从门洞里出去点数，露水打湿了履尖。简上写着：今日入城，车十一队，舟九队，另有不入名籍的商队若干。这一日她要记的头一件事，就是谁在等，等了多久。

门洞底下摆开八张几案：傧相三人，书吏四人，末尾一张矮案归她。案上一只漆匣，匣里是笔、墨、削刀，六十枚白木札。

别的史抢着要学宫暖阁里的誊录席，她要了城门口这一张。风大，手冷，可是所有的事，都要从这道门里进来。

头一批进城的是泗上两个小国，合了一支车队，一共十一辆车，轴上糊满黄泥。北边来的泥发黑，西边来的泥里掺石砂。这些日子，她看靴底看得比看脸多。验籍的次序也是礼：先节，后书，后礼单。泗上的铜节磨得只剩半边字，傧相对着旧册验了两遍才落笔画押。天下的节，一半的旧，都在这几个月里过了她的手。

为首的老使臣七十上下，捧着铜节过门槛，先看脚下，再看人。呈书开头一句写的是："自先君与王会于溟，四十有一年。"

是四十二年。

她把札子搁下："老丈，是四十二年。"

老使臣愣了愣，从怀里摸出一串磨得发亮的骨筹，一枚一枚数过去，数完了，朝她长揖："是老朽记差了。"

礼单也短：干鱼二十尾，葛布三十匹，无乐舞。国小，礼薄，薄得诚实。她一笔一笔照录，薄礼也用端正的字，对过三遍才收笔。录完，她在名籍上把那个年份刮了。刮过的简面发白，也薄了一层。她不喜欢刮简——简刮过三回就得换，换了就得重誊，重誊的字总不如头一遍老实。

旁边一位傧相笑道："王家的姑娘，记性自然好。"

她没有应，只把刮过的那枚札压在镇石底下，等它干。

午前，鼓声先到。

谷国的车队进得比谁都快。二十二乘革车，马蹄包着铜，踏在石道上像一口平底的大钟。谷国在西边山里，同熊罴打了三代仗，兵气像是从娘胎里带出来的。世子磐立在头一乘的辕上，不扶轼；过了门洞才跳下来，靴跟一磕，响亮的一声，像替全城行了个礼。看的人叫好，叫好声顺着墙根滚进城去。

她记：谷侯世子磐，革车廿二，献马六十。写完，自己又读了一遍。她原以为，今日最会被传抄的，就是这一行。

随谷国之后又过了几家。东海边上来的一家带着乐人，乐人抱着笙，冻得缩成一团，进了门洞才敢喘气；再往北来的一家全是马，人倒像是随行的。她一一记下，哪家喧，哪家静——简上不长这些，眼睛里长。

轮到下一国时，坡道上出了事。泗上一辆粮车断了轴，粮袋歪下来，把道拦了半边。她名籍的下一行，恰是这一国：公子骥，车十五乘，从者百人。

骥的御者把马勒住，回头看他。他抬了抬手，兵就下去了，解缰的解缰，扛袋的扛袋，给那粮车垫石、正轴。泗上的车夫慌得团团作揖。骥立在车辕边看他们扛粮，手拢在袖里，像看自家场院里晒谷。随行礼官过来低声请示：后头还有一国候着，次序怎么办。

"让他们先入。"骥说。

礼官看她。她把那一行刮了，往下重写。候着的那一国千恩万谢地赶车过去，过去几乘车里人人回头张望。礼官们凑在一处低声商量：记同刻，还是分先后？末了分了先后。她的削刀，今日头一回忙起来。重写时她瞥见，骥的兵重新上车，袖上全是粮袋蹭下的白灰，像落了场早来的雪。泗上的老车夫朝这些兵又作了一揖，兵们摆手，白灰袖子扬起来，倒像是还礼。

午后有一刻空。仓上一个小吏来她案前对数，嘴里念念叨叨：会粮的账，三日没平，宴席一日一添，人数一日一改，平不了。对完数，人走了，叨叨声还留了一会儿。她低头看自己的简：车、人、礼。宴上多一张嘴，仓上就少一斗米。这些数目彼此咬着，咬得比朝堂上的话紧。

又来一个学宫的旧生领席位木符。短褐洗得发白，书箧比人还宽。他领了符，在墙根下站了一会儿，没处去，就又把符摸出来看了一遍。

未时起，她案上开始收进一些不入名籍的简。学宫一位祭酒的家宰投了谒，问青国公子几时过桥；跟着，北边一位权臣的傅来问，车驾过石桥了没有；再跟着，一个商号的伙计，什么都不问，只捎一句话：他家主人想知道，青国的旗在不在桥上。还有一枚出自馆中一位老夫人之手，问的是别的事，话却绕了三绕。她照实回了时辰，又多添一句：桥上风大，公子或走水路。来传话的人愣了愣，说小人只管传话。她也愣了愣——传话的不添话，添话的是她。

她把这些简单独码作一摞。掌灯时数了数，十一枚。

傧舍还来借她记的青国入城时辰，好定明日各家请见的先后——连请见的先后，都要绕着一个人排。

那一下午，傧相们争的是宴席的座次，争了半个时辰，谁也不让。会目末尾写着北境的事，没有人争。

青国的车队申时过桥。

没有鼓。车不过二十乘上下，旗收着。公子渤不在头一乘里，他走在第二乘车旁，同赶车的说话。过门洞时他仰起头，把门洞顶上的木梁一根一根看过去，数了两遍，像头一回进城的人。

门下乱了一瞬。三个各等各回音的随员同时朝他转过身；坐着的老傧相站了起来，亲自绕出几案——这一下午，谁的车驾也没能让他抬一抬身子。老傧相问他路上几日，马乏不乏。路几日，简上有；马乏不乏，问的人自己也未必去看马。可两个人一个问得认真，一个答得认真。

渤先向老傧相反揖，又叫住一个搬简的库吏："老丈，臂上的伤利索了？"库吏慌忙把简换到左手，说利索了利索了，又说托公子的福。她在案后想：那库吏的臂，是入夏修水门时伤的。此事简上没有，他记着。

门里早候着两个学宫的旧同窗，一个抢他左袖，一个抢他右袖，同时说话。他把两只袖子都留下，一人应了三句，句句带着名字。一个把剑穗换了新色的少年世子，在他侧面转了两转，终于上前拱手报了家门；渤还礼，顺口叫出了他兄长的名字。那少年愣了愣，涨红了脸退回去，同身边同伴急急说了句什么。同伴不信，又回头看。

他走到墙根，在那旧生跟前停下："学宫的？算学？"

旧生的耳朵一下子红了。

渤把他领到仓上小吏面前，只说："会粮的账，三日没平。他一晚能平。"小吏看看那身旧短褐，又看看渤，拱了拱手。事就成了。从头到尾，四句话，她数着。仓上小吏走的时候，腰比来时直了些。

渤往前走，原先围着他的人慢慢让开，又慢慢合拢，像水让开又合上。人堆里，谷国的老傅低低吐出两个字："做态。"说完，踮起了脚。

桥市那头，两个马贩子吵了半晌的价，忽然就讲成了——有人从门洞往那边传话，青国的旗过了桥。先前咬死不落价的那个，落了价。傍晚她听傧舍的人说，西市连赁席的价钱，都要先问一句青国馆舍的远近。她不懂行情，只把"远近"两个字记下了。

申时末她才觉出饿。傧舍一个小吏见她一直没挪窝，塞给她两只南边来的蜜渍青梅。她一手执笔，一手把两只梅都吃了，吃完才想起简怕潮怕黏，忙去洗了三遍手。梅核没处搁，拿梅叶包了，塞进袖子。梅叶是香的。

日头偏西时，城像吃饱了的兽，慢慢有了自己的动静：各馆的烟升起来，先到的已经派人出来递话、还礼、探路。简上的国，变成了街上的国。

暮鼓后，棣馆来人：他们家的世子，点名点不到。

老傧相案头的简堆得比灯还高，摆了摆手。她说，我去。馆里两个小仆提灯跟着——名籍上不能空着一行。

石堰下的水声，比城门口的鼓声老实。菖蹲在堰石上，怀里一块木牍，手里一根烧过的炭条。木牍上画着水门、堰、桥、泊位，该记数的地方都有数，密得像一页账。旁边的舟子受宠若惊，还在比划：水位，风向，哪个月礁石露头。舟子说一句，他点一下头，炭条不停。堰口的水一层压着一层翻，翻得很有耐心。

菖头也不抬："阿姊是史官？简上一定有——西边那条水，在山里是青的，到这儿就黄了。是哪一段黄的？"

她答不上，说，回去替你查。话一出口就悔了：她哪有工夫。菖把木牍往怀里一收，像收一块饼，应了声好，又低头去画。他画到桥洞，把桥洞里泊的一条小船也收了进去，连船头的鱼篓都点了两点。炭条用秃了，他就在靴底磨一磨。

馆仆劝："世子，潮气上来了。"

菖指着堰口："水要下来了，你看。"

馆仆不看。过了一阵，堰上的水当真响了一声，涨了半寸。菖看的原来不是画，是这个。她又多站了片刻——她也想看看，这道堰画完了是什么样。

回程要穿过桥市。沧国商队的席棚没收，灯点着，案上摆着算筹、小铜秤、半匣珠贝。管事的是个女人，看不出年纪，袖口挽着。

青国公子站在案前，身后只跟一个背简的门客。他俯身问了句什么，女人拨了几根算筹，摆在他面前。他把一枚刀币推回去。她不动。他又添了两枚。她把三枚一并收了，从匣底取出一枚封了口的小简，双手压进他掌心。自始至终，眉毛都没抬一下。

渤走时是笑着的，不像吃了亏的笑。

她在心里记下一桩无用的见闻：青国公子，在桥市把一件东西买贵了。

她抱着当日诸简去档库交割。傧舍门前张了榜，明日通谒用的名籍新誊在上头。灯下立着一个人，从上排看到下排，看得很慢——旁人路过，都只扫一眼自家关心的那几行。风把灯带得歪了歪，他抬手挡了挡，接着看。

公子铎。他那一国未时前后到的，车马不响，她险些没记住他们入城的时辰。

他忽然开口，声音不大："这一行，和北边那一行，是同一个人。"

两国的随员册上各有一名御者，名字只差一个偏旁，像兄弟，也像同一个人写了两遍。一个名字在东边一国的册上，一个在北边一国的册上，若不是有人把榜从头看到尾，这两行一辈子不会碰面。

老傧相赶来，对着榜看了许久，什么也没问，只吩咐："今夜就改。"铎不等谁道谢，也不看谁，走了。榜下的人这才活过来，交头接耳，声音压得很低，有两个已经起身往档库方向去了。

她入史馆三年，没见过这样的事：两行各自都对，合起来才是错的。

夜里，老师把馆舍名籍交到她手上："对完再睡。"又看她一眼，"你今日误了暮食。"他什么都知道。他把一盏灯拨亮，推到她那头。

她一册一册对过去。日间刮改的次序，平了；礼单的数目，她重新加过一遍：献马二百六十有奇，献犬四十，帛若干车，珠玉按匣计——都不大，真正的大会还没开，这些只是进门的脸面。册上只一处不平：东边的松馆，紧挨青国馆舍的那座，住进了西北来的一家，原先该住桂馆。换馆的文书齐全，礼数、车马、随员一件不差，理由那一栏，空着。被换去桂馆的那一家，从头到尾，没有一句怨言。她翻回前日的底册：前日定馆的时候，这一家安安静静领了桂馆的钥，没有人多看一眼。两日之间，隔着的，不过是一支青国车队进城的工夫。

降了馆而不怨。这五个字她搁在心里，不知该归在事实，还是归在心里。

对完，她又想起白日里一个等着验籍的随员，在案前笑眯眯地同她闲谈："这样的名籍，一日誊几份？""都收在哪儿？""要是走了水呢？"她照实答了：誊两份，档库、礼房各存其一。此刻夜深想起来，第三问不大像闲谈。

她到底还是去了库房，把泗上旧约的简束解开。三道编绳，一股旧漆气，先君的名字在第二行，"溟"字末笔的漆剥了。她在灯下把那一年重数了一遍：天邑之岁，四十二年，简上不假。数完卷好，绳结打回原样，像没有动过。回来讲给老师。老师说："他们以会于溟那年起数，我们以赐胙那年起数，两边都不算错。"

"那简上记谁的？"

"记天邑的。"

灯芯短了一截。老师把简册收回去，没有再说什么。他教她认字的时候，没有教过这一层。

她没再问。她只是想起那位老使臣，摸出一枚一枚骨筹数完，朝她长揖，说"是老朽记差了"。他没有记差。他只是不住在天邑的岁里。她忽然想起白日里刮那一处时，手起刀落，快得很。往后这一刀，怕要慢了。

末了她顺手把商册也对了。桥市那家沧国商队，名籍在尾页：沧，杜若，贩珠贝。这一整日，没有一个人来问过这一行；也是这一整日里，唯一一个没向她打听过任何事的名字。而青国公子的名字，今日在她案上过了十一遍。

馆舍对了，礼单对了，名籍对了。她把诸简收进漆匣，另取一枚新札写日录。简尾照例要署誊录人的名字，她写得很小：史素。而后写：是日，晴。诸国入邑，礼成。

笔悬了一悬，又添三个字：无大事。

灯花爆了一下。她想，明日简上还有七队，城外那些火，此刻还亮着。而今日真正要紧的事——谁在等谁，谁把馆舍换到了谁的隔壁，谁不肯少收一枚刀币，谁画完了那道堰——一件也不在简上。

她吹了灯。
